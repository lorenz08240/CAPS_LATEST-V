# BuildLab Product Launch Video — Google Flow Director's Playbook

This master guide provides the exact prompts, camera motions, settings, and visual assets required to generate a cinematic, Apple/Google keynote-style product launch trailer for **BuildLab** using **Google Flow** (Google Labs Veo / Scenebuilder).

## CRITICAL: How to Prevent Google Flow from Warping the Screen Looks

AI video generators (Veo / Imagen / VideoFX inside Google Flow) often distort text and melt UI buttons if prompted incorrectly. Follow these 4 strict rules to keep the screens **100% sharp, pixel-perfect, and true to life**:

1. **Keep Motion Slider at 2 to 3 (Never exceed 4)**:
   High motion values force the diffusion model to regenerate pixels frame-by-frame, turning text into illegible gibberish. Use Google Flow's built-in **Camera Control** (Dolly / Pan / Truck) for movement instead of diffusion noise.
2. **Treat the Screen as a Physical Studio Display**:
   Anchor the prompt by describing a high-end OLED studio display or laptop screen on a dark studio table. This forces the model to respect the display as rigid glass geometry rather than abstract art.
3. **Use Camera-Only Motion Directives**:
   Never say *"the user clicks"* or *"the interface animates"*. Only describe external cinematic camera movement (*"slow dolly push-in"*, *"gentle horizontal slider tracking"*, *"subtle shallow depth-of-field rack focus"*).
4. **Include the Mandatory Screen Preservation Clause in Every Clip**:
   Every prompt in this guide ends with the universal safeguard clause:
   `The on-screen interface typography, charts, text labels, and buttons remain completely static, rigid, crisp, and unwarped with zero morphing or hallucinated artifacts.`
